Summary

A reading companion built from scratch for AO3

Archive of Our Own (AO3) is a free, ad-free, open-source fanfiction archive run by the nonprofit Organization for Transformative Works, hosting millions of fan-written works across every fandom. It's deliberately minimal, which leaves room for tools like this to fill in the gaps.

AO3 Enhancer is a browser extension built from scratch on top of that archive. It runs on both Chrome and Firefox from a single codebase, adding the search, reading, and filtering tools the site itself doesn't offer — history-aware filtering, a synced read-works cache, and a wrapped-style yearly stats page.

Everything lives in the extension popup — Settings, Saved searches, Word Replacer, and AO3 Wrapped — so readers never have to leave AO3 to tune how it works for them.

Tech Stack

JavaScript WebExtensions API Chrome Manifest V3 Firefox Add-ons Browser Storage / History API

Details

  • Search filters: select multiple ratings at once, switch tag matching from AND to OR, a dedicated "main ship" field with AO3 autocomplete, a default search language, and a one-click filter for single-chapter works
  • Reading experience: estimated reading time and average words-per-chapter on work blurbs and work pages, based on a configurable reading speed, plus clearer "Chapter X of Y" labels
  • Always-block lists for tags, characters, relationships, and authors — applied site-wide or search-only, and carried through pagination
  • Read-history awareness: an optional browser-history check on top of AO3's own history, backed by a synced local cache, so already-read works get filtered out automatically
  • Saved searches, a Word Replacer for swapping words or phrases inside a fic, and an AO3 Wrapped page — fics read, words read, estimated time spent, and top fandoms/ships/tags for the year

Learning Experience

Building everything from scratch meant designing the content-script injection, filtering logic, and popup UI without a reference implementation to lean on — every feature had to be reverse-engineered from how AO3's own pages are structured.

Getting the same code running on both Chrome and Firefox surfaced the practical differences between Manifest V3 and the Firefox WebExtensions model, particularly around background scripts and storage — a good forcing function for writing browser-agnostic code instead of chasing one platform's quirks.
