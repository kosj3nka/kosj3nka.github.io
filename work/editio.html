Summary

A magazine that shops itself out

Editio is a content-to-commerce platform for Croatian lifestyle and hosting editorial: long-form articles on destinations, culture, and the makers behind them, sitting in a restrained magazine grid instead of a typical blog template.

A designer/maker layer cuts across the whole site — the same person can be an article's subject, a pin on the destinations map, and a storefront in the market, without three separate content models to keep in sync.

Tech Stack

Next.js 16 Sanity CMS next-sanity GROQ Portable Text react-simple-maps styled-components Vercel Analytics

Details

  • Sanity Studio as the editing surface, with a custom Structure Builder sidebar grouping articles by Interior Design, Architecture, Physical Art, and Art of Hosting instead of one flat document list
  • Portable Text body copy with embedded custom blocks — a "Shop This Story" product callout, image galleries, and pull quotes — so commerce lives inside the writing, not bolted beside it
  • Designer storefronts support multiple platforms (Shopify, WooCommerce, Etsy, or a plain external link) through one conditional schema instead of one integration per platform
  • A destinations map built on geopoints attached to designer locations, so a studio in an article can also surface as a pin to visit

Learning Experience

The main lesson was modeling references instead of duplicating them — using Sanity's references() in GROQ to query "which listings mention this designer" instead of maintaining a hand-kept array on both sides that inevitably drifts out of sync.

Deciding reference vs. embed for every field (a designer is reused and queried on its own, so it's a reference; an SEO block only ever lives inside its parent, so it's embedded) turned out to be the single decision that kept the schema from sprawling into a monolith.
